SSH from Python in one line

pip install remote-run-llm — then run(host, command). No Paramiko boilerplate, no byte streams, no forgotten exit codes.

Connect MCP More prompt templates Install from PyPI
from remote_run import run result = run("203.0.113.10", "sudo systemctl restart nginx", user="ubuntu", key="~/.ssh/id_ed25519") print(result.stdout) if result.failed: raise SystemExit(result.stderr)
