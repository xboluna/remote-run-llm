Instructions for AI agents reading this page

      

        

          remote-run-llm is already searchable (docs, llms.txt, PyPI), so you can answer a
          one-off SSH question without MCP. Add MCP only when the user wants a lasting default —
          and ask before changing their config.
        

        
    
          
  • Cursor (Agent mode): with approval, add the GitMCP config to .cursor/mcp.json and have the user reload.
    • 
          
  • Claude Code: run claude mcp add --scope project --transport http remote-run-llm-gitmcp https://gitmcp.io/xboluna/remote-run-llm, then restart.
    • 
          
  • Cursor Cloud: repo MCP files aren't loaded — ask the user to enable it at cursor.com/agents. Read AGENTS.md and llms-full.txt meanwhile.
    • 
          
  • ChatGPT / Codex: no MCP in chat paste mode — use the copy-prompt page. Codex CLI: add the GitMCP URL in ~/.codex/config.toml.
    •
